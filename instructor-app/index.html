핀란드식 설계 원칙
1. 학생의 배움 중심

교사의 가르침보다 학생의 배움에 초점을 맞춰 설계

2. 실생활 연계가 진짜여야 한다

학생 주변의 것들로 구성. 수학의 필요성을 스스로 느끼게

3. 현상에서 출발한다

실제 세계 문제 → 증거 수집 → 기존 이론과 대조 → 새로운 이해

4. 학생이 질문을 만든다

교사는 조력자. 학생이 스스로 틀을 잡은 문제를 탐구

5. 쉬운 답이 없는 큰 질문

학생이 스스로 큰 질문을 던지도록 이끄는 방식

칸아카데미

강점
  • 시각적 원리 설명단계별 스캐폴딩이 촘촘하고 명확하다
한계
  • 동기가 없다"소인수분해란 무엇인가"는 설명하지만 "왜 배우는가"는 없음
  • 천장이 낮다절차 숙달에서 멈춤. 구조적 사고로 넘어가지 않음
  • 맥락이 장식이다피자·사탕 맥락은 계산 포장일 뿐, 수학적 본질과 무관

한국식

강점
  • 정교한 문제 구조약수 개수, 서로소, 완전제곱수 등 개념 간 연결이 깊음
  • 체계적 난이도 설계상위권 학생을 끝까지 밀어붙일 수 있다
한계
  • 동기가 없다학생은 왜 이 구조를 배우는지 모른 채 훈련함
  • 발견이 없다개념을 먼저 주고 확인하는 방식
  • 오개념이 숨는다절차를 외우면 틀리지 않아 오개념이 드러나지 않음

핀란드식

강점
  • 동기가 먼저다학생이 필요를 느끼고 나서 개념이 등장
  • 발견이 있다학생이 차이를 설명하려다 개념에 스스로 도달
  • 오개념이 드러난다탐색 과정에서 잘못된 직관이 표면으로 올라옴
한계
  • 구조적 정교함이 없다발견에서 멈추고 깊어지지 않음
  • 상위권을 못 밀어붙인다발견 이후 도전이 없음
  • 교사 의존도가 높다발문 설계 역량이 없으면 그냥 활동으로 끝남

세 접근법의 한계는 같은 문제의 세 단면이다.
math-explorer는 단순히 장점을 합치는 게 아니다.
각각의 한계가 서로를 보완하는 구조를 설계하는 것이다.

1단계 — 모둠 나누기 (소수 발견)

상황
  • 우리 반 28명을 체육 시간에 똑같은 크기의 모둠으로 나누려 한다.
    몇 가지 방법이 있을까?
학생 탐색 과정
  • 28 = 2 × 14
  • 28 = 4 × 7
  • 28 = 7 × 4  ← 같은 건가 다른 건가? (첫 번째 막힘)
  • 28 = 14 × 2
  • 28 = 28 × 1 ← 1명짜리 모둠은 모둠인가? (두 번째 막힘)
전환 발문
  • 그런데 우리 반이 29명이라면?
학생이 도달하는 발견
  • 29는 1과 29로밖에 안 나눠진다
  • → "이런 수"가 뭔가 특별하다
  • → 학생이 이름을 붙이고 싶어진다 (소수 개념 자연 도달)
앱 구현 방식
  • 화면에 28개 점을 보여준다
  • 학생이 직접 배열을 만든다 (터치로 행/열 조정)
  • 가능한 배열이 완성되면 기록된다
  • 29로 바꿨을 때 배열이 하나밖에 안 만들어진다
막힘 설계 2개

막힘 1 — 4×7과 7×4는 같은가 다른가?

학생이 느끼는 혼란
  • 수학시간 → 4×7 = 7×4 (교환법칙, 같다)
  • 체육시간 → 4모둠×7명 ≠ 7모둠×4명 (다르다)
앱이 유도하는 탐색
  • "4모둠에 7명씩"과 "7모둠에 4명씩"
  • 운동장에서 실제로 다른가?
  • 둘 다 그려봐라
학생이 도달하는 발견
  • 현실 → 다르다 (모둠 수가 다르니까)
  • 수학 → 같다 (28명을 나눈다는 본질은 같으니까)
  • → "수학에서는 4와 7이라는 수의 쌍이 중요하다"
  • → 약수 쌍 개념 자연 도달

막힘 2 — 1명짜리 모둠은 인정하는가?

학생이 느끼는 혼란
  • 1×28 = 28 이니까 수학적으로는 맞다
  • 그런데 28모둠에 1명씩은 모둠이 아니다
앱이 유도하는 탐색
  • 1명짜리 모둠을 인정하면
  • 모든 수가 항상 "1과 자기 자신"으로 나눠진다
  • 그러면 29도 나눠지는 셈이 된다
  • 29가 특별한 이유가 사라진다
  • → 1을 제외해야 29의 특별함이 살아난다
학생이 도달하는 발견
  • 1은 제외하는 게 수학적으로 더 유용하다
  • → 학생이 규칙을 스스로 정한다
  • → "소수에서 1을 제외하는 이유"를
       교사가 설명하는 게 아니라
       학생이 필요를 느껴서 결정한다

목표

상황 제시 (4개 동시)

  • 건물 지하지상 기준 아래 2층

  • 해저 탐사해수면 아래 200m
전환 발문
  • "이 네 상황의 공통점이 뭘까?"
  • 예상 답변: "부족하다", "아래다", "기준보다 적다", "반대쪽이다"
  • 유도: "맞다. 모두 어떤 기준보다 아래/부족/반대다. 그 기준이 뭔가?" → 기온의 기준=0도, 고도의 기준=해수면

막힘 1 — 표현의 막힘

유발 상황
  • "이 상황들을 우리가 아는 수로 표현해봐라"
학생 혼란
  • 0, 1, 2, 3…으로는 '기준보다 아래'를 표현할 방법이 없다
탐색 유도
  • "영상 5도는 5라고 쓴다. 영하 5도는?"
  • "수직선 위에 영상 5도를 표시했다. 영하 5도는 어디에 있는가?"
발견
  • 0의 왼쪽/아래에 수가 있어야 하는데 표현할 기호가 없다
  • → 학생이 새로운 기호의 필요성을 스스로 요구
연결
  • 2단계 절댓값

막힘 2 — 방향의 발견

유발 상황
  • "영상 5도와 영하 5도. 둘 다 '5'인데 같은가?"
학생 혼란
  • 숫자는 같은데 의미가 정반대다
탐색 유도
  • "수직선에 두 수를 표시해봐라. 같은 '5'인데 0을 기준으로 어느 쪽에 있는가?"
발견
  • 같은 숫자라도 방향(기준의 어느 쪽인가)이 다르다
  • 숫자는 크기, 부호는 방향 → 양수와 음수의 구조
연결
  • 2단계 절댓값(크기)과 부호(방향)의 분리
최종 발견
  • 기준점(0)이 있고, 그 양쪽으로 방향이 있는 수가 필요하다
  • 한쪽은 +, 반대쪽은 − → 양수와 음수 개념 자연 도달
  • 0은 '없음'이 아니라 '기준'이다
앱 화면
  • 수직선 만들기 — 학생이 직접 0을 기준점으로 놓고, 양쪽으로 눈금을 그려 네 상황을 한 수직선 위에 배치
핵심 교육 장치 2개
  • "0은 기준이다"중1이 흔히 0을 '없음'으로만 이해하는 오개념을 1단계에서 미리 깬다. 2단계 절댓값(0으로부터의 거리)의 발판이 된다.
  • "숫자=크기, 부호=방향"의 분리품질 헌법 원칙 1(계산과 사고 분리)과 맞고, 2단계 절댓값으로 직접 연결된다.
